# MS8AT Global · Future Flow · J-Tec

Публичный комплект презентационных материалов MS8AT Global: оборудование, локальная автоматизация, Dashboard/MQTT, Android/PXE, вендинг и проекты запуска цифровых площадок.

**Языки:** русский → 中文 → English.

**Публичный сайт:** GitHub Pages этого репозитория.

**Корпоративный сайт:** [ms8at.by](https://ms8at.by/)

**Проекты запуска:** [jtec.tech](https://jtec.tech/) и [future.shop.by](https://future.shop.by/)

## Состав

- 6 готовых видео: быстрый и короткий форматы на трёх языках;
- 3 заполненные бизнес-анкеты: RU, 中文, EN;
- 3 редактируемые PowerPoint-презентации с Android/PXE;
- 3 PDF-версии для просмотра;
- публичная витрина оборудования и программного контура;
- галерея реальных фотографий Дунгуаня, производственной среды и образцов оборудования с указанием источников и лицензий;
- план запуска jtec.tech и future.shop.by.
